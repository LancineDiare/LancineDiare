# Hi, I'm Lancine👋

I'm from Guinea and based in the Philippines. I'm an Information Technology student at Asia Pacific College, an Operations Team Leader at TELUS Digital, and a developer interested in building practical tools for education, business, and communities.

My background in Sociology, management, teaching, and customer service shapes how I approach technology: understand the problem, respect the people involved, and build something useful.

## 💻 What I Work On

- Web applications and API development
- Language translation and learning tools
- Document management platforms
- E-commerce and community applications
- Project planning and team collaboration
